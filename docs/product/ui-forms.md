# 工作区连接表单

创建工作区后，设置按规划连接、字段映射、执行、仓库四个固定任务组织。宽容器使用侧栏导航，窄容器使用有标签的原生任务选择器，空间不足时选择器独占一行以保留完整任务名；当前任务位于工作区长说明之前。原生form/label/input/select配合少量私有呈现，确认状态来自既有source。

已确认的规划连接先显示来源、项目与确认摘要，显式“编辑”才展开字段；pending、error或未确认配置保留相应操作与恢复入口。执行绑定只说明绑定事实，不推断会话、模型、CI或发布就绪。映射确认不能盖过pending、失败或未应用草稿。

工作区设置的安全错误与恢复出口位于任务面板之外，切换任务仍可见；字段错误继续保留自己的关联。进入或重入设置只调整既有局部滚动区，使当前任务导航可见，保持键盘焦点；后台读取、迟到响应、主题和尺寸变化不重置阅读位置。

字段有稳定唯一标签、简短帮助与错误关联；同名字段/选项保留来源ID，已删除选项显示原身份。主动作最低44px，颜色和字体继承Host；窄宽字段纵向排列，长路径不撑页。

原生required校验聚焦第一个无效输入。异步错误只响应当前表单的用户提交；仓库绑定的中间configured不提前结束焦点归属，确认读回失败仍聚焦安全摘要。后台刷新不无条件抢焦点。

pending、configured、local_only、unknown、failed、active各自使用现有安全source结果；Provider确认/重验前不称已保存。unknown要求确认，失败保留草稿，重试沿用既有意图键和scope规则。

同一 source、工作区与绑定/项目 scope 下，返回工作区或重入设置只改变可见性，保留项目、映射和仓库草稿及未决 intent。真实卸载表单才结束该本地尝试的观察，不撤销已接纳的远端操作，也不解绑已确认配置。凭据由Host管理，不新增密钥输入或回显句柄。列表组合保持外层frame覆盖动作，直接嵌套app清零重复padding。

Host确认与完整发布UAT分别记录，详见[实施计划](../exec-plan/completed/2026-10-29-mmp-ui-forms.md)。

连接失败使用本次命令的安全结构化原因，界面不解析平台原文：

| 平台证据 | 用户下一步 |
|---|---|
| 凭据被拒绝 | 在宿主检查或更新凭据 |
| 明确报告所需权限不足 | 在宿主补充授权 |
| 项目不存在或当前授权不可见 | 到来源平台核对项目标识与访问范围 |

普通访问拒绝、限流、网络失败、畸形响应与结果未知仍保守显示，不能猜测隐藏项目存在或把失败连接称为已保存。新目标、新读数或后续成功不会沿用旧原因；表单保留草稿，只响应当前提交的错误焦点。实现与证据见[连接诊断计划](../exec-plan/completed/2026-10-30-ui-connect-diagnostics.md)。
