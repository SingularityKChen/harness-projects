# 响应式工作项详情

所有工作项进入唯一原生模态详情。桌面右侧布局仍保持modal：背景可见但inert，不能宣称主列表可同时操作。

断点依据实际工作区可见宽度。至少1200 CSS px时，右侧340px详情、主列表预留356px；更窄时覆盖显示，最窄320px仍可读。几何由组合页与drawer同一owner管理，resize不重挂载、不重发业务动作。

标题和44px关闭动作位于头部，正文独立滚动；可见高度不足时，对话框整体也可滚动，使标题、关闭与正文动作都有可达路径。长标题、来源身份、时间和路径保留并换行；超长标题自身可滚，不通过隐藏事实适配宽度。

打开聚焦可访问标题；Tab/Shift+Tab约束于可用控件，跳过disabled和隐藏项。Escape只关闭一次；opener仍在列表中则回焦，否则聚焦列表标题。内容变成遮蔽/不可用时不保留旧标题、target或动作。

执行、开始工作、交付和刷新继续消费既有source/reader，布局不创建业务状态。本地布局/焦点测试与实际Host呈现分别记录，完整发布接受仍由相应工作项裁决。详见[实施计划](../exec-plan/completed/2026-10-29-mmp-ui-detail.md)。

详情几何显式拥有自身边界，外层工作区间距不会因样式装配顺序再次进入dialog。标题栏根据实际可用宽度自然换行：放大文字或窄嵌入区不足并排时，关闭动作换到下一行，标题保留可读宽度和自身滚动，不缩小文字或隐藏标题。

重排验收使用真实WorkItemApp装配（含最后插入的共享样式），以computed padding/rect和实际键盘、滚动判断；孤立详情的SSR只能证明语义。两根因、样式顺序正控和200%文字矩阵见[重排实施计划](../exec-plan/completed/2026-10-30-ui-detail-text-reflow.md)。

短高度仍为正文保留完整文字行和动作空间；整体滚到正文后可继续独立滚动正文，键盘聚焦关闭或正文动作时浏览器将其带入可见区。正常高度继续使用原正文视口，不缩小文字或截断标题。
