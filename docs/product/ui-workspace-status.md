# 工作区状态摘要

摘要在工作项与设置页面持续呈现既有 Host/client 读数，由生产 Panel 组合层消费；导航、字段错误与操作仍由原组件拥有。

## 事实与作用域

工作区、Planning 确认、Host transport、当前来源读取和未决操作分别展示。配置已记录不等于来源已确认；连接中断仍可保留明确标记的最后已知确认。缺读数显示未知，不能从工作区存在、执行或 CI 推导成功。

transport 必须匹配当前 workspace；来源名称与 `reconciledAt` 还必须匹配当前 Planning binding。确认时间只取 Host 来源确认时间，不以浏览器时钟或帧接收时间替代。身份不匹配时不展示旧名称或时间。来源名、映射来源和确认时刻还需已观测的 available/read_only/degraded 读取许可；未知或 unavailable 帧即使残留同 scope 元数据也隐藏这三项。能力判据先于 transport，因此离线不覆盖未知或拒读；授权离线/陈旧帧仍可保留明确的最后已知来源事实。reason 可代表已提交的部分读取，不单独充当整体撤权判据。

映射操作要求 workspace、binding、project 三项一致。仓库快照没有 workspace 身份，因此只显示保守的操作概述；观察到 workspace 换代后标记为先前操作。摘要不显示本机路径、原始 Provider 错误或凭据。

pending、failed、unknown、local-only 分别保留原含义；摘要不发请求、不决定权限、不写 Planning 状态，也不建立第二个订阅 store。

## 布局与可访问性

正常首屏只显示一次工作区身份，并分别标明宿主 transport 与来源读取观察。普通文字、宽容器的紧凑行自然高约 40–48 CSS px；原生 `details/summary` 可 Tab 到达、用 Enter/Space 披露来源、Planning 确认、字段映射及最后完整确认。异常操作始终在披露之外；窄屏先排列宿主与来源观察，再完整显示长身份，避免把异常挤到长名称之后。极短高或大文字时状态区最多占父容器一半，可局部滚动完整文字，正文保留独立空间。主区为基线 Gate 提供局部滚动回退；有界外壳已有正文 owner 时，该回退没有额外滚动范围。

已有观察时刻按绝对本地时间显示，并标出 IANA 时区；`time.dateTime` 保留原始 ISO，披露中也可读原值。无效时刻只说“时间未知”，不以当前时钟补事实；目标日期继续是 date-only。

摘要只公告 transport 与当前来源读取观察的变化。时间推进不公告；操作继续由字段表单公告。列表保留显式刷新、失败和连续可读时的安全数量变化，未知或不可读时清空旧数量。原生模态打开时，由详情内的 notice 公告，背景摘要遵循原生 inert。

## 验收边界

真实 source 矩阵、生产 apply、DOM/AX 观察、安装候选和人类验收分别记录。DOM live 文本变更次数不能证明屏幕阅读器语音效果；自动化安装也不替代 #449 或 R1 的人类裁决。
