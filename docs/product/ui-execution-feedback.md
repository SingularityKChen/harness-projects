# 执行与交付反馈

工作项详情依次展示交付谱系、执行上下文与显式开始工作。规划状态、运行结果和所属提交的CI事实独立显示；运行完成或检查通过不会把规划状态改为完成。

关键状态、最后确认时间、人工承接和下一步动作保持可见。工作树、分支和谱系来源可通过原生“执行来源”或“谱系来源”展开，键盘Enter/Space可操作。缺口、未知、失败、陈旧及候选关系保留原含义，不合成总体成功灯。

开始工作只在用户提交后执行。结果未知时先“读回并恢复”，失败保留草稿。若提交期间禁用按钮使焦点丢失，当前结果落地后回到恢复动作；用户已移到其他控件、关闭表单、断开连接或切换目标时不抢焦点。Host/Core与既有client仍拥有事实和意图，呈现层只管理局部DOM焦点。

视觉继承Host字体、主题、焦点和间距token，不新增主题状态或UI框架。窄区采用垂直分节、可换行长身份和44px动作。详情容器与文字放大重排由[详情说明](ui-detail.md)单独定义。

本地组件、受控浏览器和负控证据见[实施计划](../exec-plan/completed/2026-10-30-ui-execution-feedback.md)；它们不替代安装Host、人类UAT或R1发布裁决。
