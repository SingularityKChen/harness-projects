# 工作区视觉框架

当前业务UI以工作项、连接设置和唯一详情为入口。未交付页面不作为导航入口。Host负责主题和原生全局导航，插件只提供局部业务呈现。

`packages/ui/src/workspace-presentation.ts` 的私有 `WORKSPACE_STYLES` 由实际入口消费；不新增公共组件API、路由或业务store。字号和前景/背景继承Host，焦点和单一动作强调消费公开 `--dsw-*` token。

间距采用4/8/12/16/24等效尺度、细边框和紧凑中文排版。文字说明来源、权威和新鲜度；颜色只作辅助。主动作最低44px，focus清楚可见。没有新增动画或独立主题开关。

1440/1200/1024和窄宽中标题、状态、元信息可以换行；页面不横滚，八列表格允许局部横滚。长文字和身份完整保留，不能通过隐藏字段来适配空间。

确认、最后已知、正在处理、离线和无权限沿现有ui-model/Host投影显示；CSS与本地路由不生成业务事实。共享样式不能授权动作，也不能把未确认的结果称为已保存。

本地浏览器、同构建包报告和官方Web profile呈现检查各自有证据边界。完整安装Host产品接受、运行时权限和R1仍分别验收。实现记录见[工作区视觉框架计划](../exec-plan/completed/2026-10-29-mmp-ui-frame.md)。

规划来源的只读提示仅说明规划内容的读取边界。开始工作仍由当前仓库的 Development 能力独立决定；只读规划不等于禁用工程执行。相关组合验证见[实施计划](../exec-plan/completed/2026-10-30-ui-planning-readonly-scope.md)。
