## Global Constraints
每个能力一条可独立审阅、回滚的提交；规划轴不因工程事件推进。review 用 `gh-review`，作者操作用 `gh` / Git。禁止把录制会话、Fake Provider、真实临时 Git/SQLite 自动化推导成真实 Desktop、在线 GitHub 或模型验收。保留用户已有工作树与原组合检出。
