## Design / Spec

采用三名独立子评审与协调者复核；模型为 `gpt-6.1-sol` 对应宿主 preset，状态拥有/重组使用 xhigh，执行和设置使用 high。Superpowers 管独立审查与验证，Qian 管系统边界与整体闭环，First Principles 管需求、不变量和反例。

先建 P0–P3 风险矩阵，再完整覆盖代码、产品、架构、测试、反例与 issue；逐 PR 一次提交全部 inline。选择修复根因及永久回归，舍弃只改按钮条件或把已有后续 issue 的范围强塞入当前 PR。

## Global Constraints

保留七条系统不变量、依赖方向、单工作区范围和账号边界。评审用 `gh-review` / `Singularity-AI-Bot`；修复、提交、回复与合并用 `gh` / `SingularityKChen`。根工作区原有未跟踪文件不属于本轮。

本记录与本 PR `docs/review/pr-404-mmp-review.md`、评审索引、现有 ExecPlan 的修复记录组成文档增量；产品变更归各自 PR 文件集合，不交叉代修。只处理四条关联 issue 的验收；不写规划 Status、Priority、Size、Iteration 或 blocked-by/blocking。
